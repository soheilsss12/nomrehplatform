## در GitHub چه چیزی است

- `main` → یک فایل: `prompt-next-agent-fa.md`
- شاخهٔ این جلسه → همان یک فایل + فایل‌های تشخیصی که من ساختم
  (`.github/workflows/`, `diagnostics/`, `docs/`)
- **فایل/زیپ پروژه هنوز به هیچ شاخه‌ای نرسیده.** آخرین commit ریپو همان
  `2a858da` («Add files via upload») است و درختش فقط یک فایل دارد.

پس «الان همه چیز به همه چیز وصل است» درست نیست — یا آپلود نیمه‌کاره مانده،
یا در جای دیگری (کامپیوتر، Drive، یا draft) است.

## چرا SSH هم راه نبود

- شما گفتید به SSH دسترسی ندارید (فقط کنسول npm در Plesk).
- من هم به `:22` نمی‌رسم و `:443` هم TLS را قطع می‌کند.

## نتیجه

کارِ «به هاست وصل شو» از این سمت انجام‌شدنی نیست. آنچه انجام‌شدنی است:

1. کد در GitHub → من می‌بینم، جراحی می‌کنم، تست و build می‌گیرم.
2. فایل PHP در `httpdocs` → شاهد لایه‌ای می‌دهد (قبلاً داد).
3. تصمیم لایهٔ شبکه → هاستینگ/کایا یا تغییر سرویس‌دهنده.

هیچ‌کدام از این سه، «تأیید شده» نیست تا وقتی یک تصحیح واقعی دیده شود.
